# Exercise Guide - C# + MudBlazor (Beginner)

## Goal
Build a dynamic CRUD for `Persona` where:
- form fields are generated by reflection;
- grid columns are generated by reflection;
- each person is saved as a JSON file in a local folder.

## Project Structure
- `src/PeopleExercise.Web/Models/Persona.cs`
- `src/PeopleExercise.Web/Configuration/StorageOptions.cs`
- `src/PeopleExercise.Web/Services/IPersonStorageService.cs`
- `src/PeopleExercise.Web/Services/FilePersonStorageService.cs`
- `src/PeopleExercise.Web/Services/IPersonSchemaService.cs`
- `src/PeopleExercise.Web/Services/ReflectionPersonSchemaService.cs`
- `src/PeopleExercise.Web/Components/DynamicField.razor`
- `src/PeopleExercise.Web/Components/Pages/People.razor`

## Checkpoints
- [ ] Create a new person from UI and verify file `{Id}.json` exists.
- [ ] Restart app and verify persons are loaded from disk.
- [ ] Edit one person and verify JSON is updated.
- [ ] Delete one person and verify JSON file is removed.
- [ ] Add a new property in `Persona` (supported type) and verify new field + new grid column appear automatically.

## Supported Types (v1)
- `string`
- `int`
- `decimal`
- `DateTime`
- `bool`

## Local Storage Path
Set in `appsettings.json`:

```json
"Storage": {
  "PeopleDirectoryPath": "Data/People"
}
```

You can use an absolute path if needed.

## Manual Resilience Tests
1. Corrupted JSON file:
- create an invalid json file in the people folder;
- open `/people`;
- verify app does not crash and warning snackbar appears.

2. Missing folder:
- delete `Data/People`;
- open `/people`;
- verify folder is recreated.

3. Permissions:
- point storage path to a non-writable directory;
- save/delete a person;
- verify UI shows storage error.
